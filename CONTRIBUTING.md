# Contributing

This repository is frozen as a historical validation benchmark for Agnara 0.1.0a8.

**Pull Requests are not accepted**, as modifying the code would invalidate its purpose as a point-in-time reference for the framework's capabilities at version `0.1.0a8`.

If you wish to explore Agnara's MCP integration with a newer version of the framework, please refer to the official [Agnara Project documentation](https://github.com/agnara-project).
