## [0.1.0] - Historical Validation Release

### Added
- Complete integration using `agnara==0.1.0a8` and `agnara-mcp==0.1.0a8`.
- Inventory capability suite: `read`, `stock`, `reserve`.
- Full authorization mapping highlighting `stdio` anonymous behaviors.
- Automated `pytest` suite validating tool discovery and invocation outcomes.
- `smoke_client.py` example implementing a robust end-to-end `mcp.client.session.ClientSession`.
- CI pipeline executing full quality gates and environment validations.
